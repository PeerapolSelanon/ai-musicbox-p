📤 วิธีอัพโหลดขึ้น YouTube
  • เปิด YouTube Studio → Create → Upload Videos
  • ลากไฟล์ .webm ที่ดาวน์โหลด หรือกด Select Files
  • ใส่ Title, Description, Tags ตามที่ copy ไว้
  • เลือก Audience → Not made for kids (ถ้าไม่ใช่เนื้อหาเด็ก)
  • กด Publish — YouTube จะ process ไฟล์อีกครั้ง
